# v0.5.8 — consolidation

Consolidates the char-level-substrate lint-understanding trunk (162 commits) onto
`main`, folds in the MCP self-heal fix, and resolves the forked v0.5.7 release line.

## Included
- **AI linter — char-level substrate.** The whole lint-understanding trunk: the
  `CharReader` predictive substrate, the dictionary meaning network, the
  understanding→trace bridge (`lint_trace`), and the reasoning verifier. See
  `native/architecture.dx` and `native/history.dx` for the full design + measured behavior.
- **MCP self-heal** (from `fix/mcp-stale-registration-selfheal`): the server
  self-heals a stale Claude Code registration so it starts for agents; `doctor`
  auto-repairs; `apply_update` re-registers after a binary-only upgrade.
- **search_web** image/web/both search + scrape-hang fix (carried from the prior
  v0.5.6/v0.5.7 line on `main`).
